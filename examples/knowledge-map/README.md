# 七年级数学知识一查表

在浏览器中打开同目录的 `index.html` 即可使用。页面自带 21 个知识点、学习要求、教材位置与关系，支持离线使用。

- 拖动节点调整位置，连线会跟随节点。拖动画布可以平移，滚轮或加减按钮可以缩放。
- 点击节点可以在当前画布聚焦并查看相邻知识点。右侧显示教学要求、教材页码和直接联系。“查看全图”恢复全局视野。
- 搜索框支持知识点、章节和编号；“一览表”可按主题查看全部条目。

## 打开本机教材

页码可直接在图谱中查阅。若要点击跳转至教材原页，请从自己已有的资料包中，把以下文件放进与 `index.html` 同级的 `教材` 文件夹：

- `B02_相关资料切片.pdf`（不等式与不等式组）
- `B05_相关资料切片.pdf`（代数式与整式运算）
- `B06_相关资料切片.pdf`（方程与方程组）

PDF 页序号对应切片中的页面，教材正文页码见知识点详情。
